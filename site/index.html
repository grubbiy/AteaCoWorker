AN HONEST STARTING POINT

A focused alternative.
Room to prove it.

Does this replace Microsoft 365 or all of Copilot?

No. The idea is to handle a useful subset of project knowledge, drafting, and editing locally. Microsoft 365 remains the source of truth. Live collaboration, email, meetings, and broader Copilot capabilities are outside this concept demo.

Does the browser demo run an AI model?

No. It uses clearly labelled, scripted responses and fictional sources. The proposed desktop app would run generation and retrieval locally. This website demonstrates the workflow, not inference quality.

Can it really run on a low-end computer?

That is a design target. Smaller local models, bounded context, and one task at a time may make modest hardware practical. Minimum requirements and useful performance must be measured on real machines before making a promise.

How would the coding agent be kept safe?

The proposal uses OS-enforced isolation, a disposable project directory, bounded resources, reviewable patches, and explicit network grants. A folder or a prompt alone is not a sandbox. This demo executes no code and proves no security boundary.

What happens to information in this demo?

Only fictional source fixtures are supplied. Notes, drafts, and settings are stored unencrypted in this browser’s local storage, with no application backend or analytics. Do not enter company information. Reset demo removes that state; browser controls can also remove cached site assets. The host receives ordinary website requests.
